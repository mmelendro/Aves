# AVES — Global, Colombia and New Zealand

The public site is [aves.bio](https://aves.bio). This checkout belongs to **`webmaster/readiness-2026-11-05`** in [mmelendro/Aves](https://github.com/mmelendro/Aves). The global/Colombia/NZ and Australian/shared-account applications use separate branches and Vercel projects. Do not merge them or assume a GitHub push publishes the site.

Account implementation is explained in the [Australian backend tour](https://github.com/mmelendro/Aves/blob/australia/preview/docs/backend-code-tour.md). My Trips is [aves.bio/account](https://aves.bio/account), supported by one shared backend for Colombia and Australia. New Zealand remains public inspiration/inquiries in development, without saved-trip support.

The application uses Next.js 15, React 19, TypeScript and Tailwind CSS. Code comments explain purpose, inputs, interactions and boundaries; static data, generated files and shared UI patterns have companion guides. Private keys and customer records do not belong in GitHub. Public source content must remain factual and media must retain its attribution.

See [historical release notes](docs/historical-readme.md) only for context. Their older paths, counts and configuration descriptions are superseded by the current guides and handoff.
