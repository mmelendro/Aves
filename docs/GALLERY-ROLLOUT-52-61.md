# Landscape rollout: roadmap items52–61

## Colombia:52–58

Five independently sourced photographs have been added for each of Sierra Nevada de Santa Marta, Caribbean, Pacific Coast and Chocó, Llanos, Amazonia and Colombian Massif. All eleven Colombian regional galleries now contain five photographs. The shared country overview alternates regions and takes two photographs from each, using the same credited records as the regional views.

Every new image retains its photographer, original file page, reuse terms, review date and original/rendition hashes. Captions describe the photograph. Historical imagery does not establish current access, services, ecological condition or sightings. A place name never establishes permission to visit a protected or culturally sensitive site.

A similarly named Estonian Utria result was rejected and replaced with a source explicitly identifying Ensenada de Utría in Colombia. Source dates remain unnormalised when incomplete or ambiguous. No Indigenous name, translation, pronunciation or audio has been invented.

Validation:684 tests passed, strict TypeScript passed, architecture audit passed with395 reachable source modules and no unreachable modules, and the78-route production build passed. Physical Safari and independent visitor checks remain open.
