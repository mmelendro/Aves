# Journal upload recovery

Published 12 November 2026 on aves.bio and www.aves.bio. Source: 1ba4c8fd13515ac180698d1c390eaa238d88b93c.

Failed uploads retain the selected copy for retry. Reopened incomplete uploads can reuse their existing reservation. Format and size checks support the existing server content verification. The interface explains the file limit and incomplete-upload quota, and offers a refresh control. Clearing a selected copy does not delete saved files.

Validation: 654 tests, strict TypeScript, source audit and production build passed. Both public aliases and live upload controls checked. Physical Safari, narrow authenticated layouts and live interrupted-file recovery remain pending. Receipts, booking documents and export remain future increments.
