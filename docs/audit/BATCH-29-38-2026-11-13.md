## Reproducible assets

Generated photo and regional-cue files are build artifacts, rather than duplicated
binary source in Git. The checked build emits them from the original repository
sources. Tracked manifests retain source/output hashes and the exact recipe.
The build fails if source photographs, geometry or recipes have changed without
regenerating and committing the manifests. A warm build verifies cached output
digests instead of recompressing unchanged images.

After an intentional photo or geometry change:

```sh
node scripts/generate-guide-map-cues.cjs
node scripts/generate-responsive-photos.mjs
pnpm test
pnpm build
pnpm check:catalogue-loading
node scripts/profile-route-bundles.mjs --check-deferred-geometry
```

No private fixtures, customer records or provider credentials enter these assets.

identity must be recorded before marking this batch published.
