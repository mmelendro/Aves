## Cleanup decisions

The static inventory now covers route purpose, root build configuration, named export candidates, dependency consumers and asset hashes. Default exports and Next entry-point names are retained rather than treated as unused named symbols. No unused direct package candidates or named-export candidates remain under this conservative inventory. This is not proof that every reachable feature is necessary.

Removed direct dependencies: @radix-ui/react-accordion, @radix-ui/react-scroll-area and @radix-ui/react-separator. tailwindcss-animate remains because tailwind.config.ts uses it. pnpm 10.34.5 regenerated only the lockfile; the shared dependency directory was not modified.

Removed six unused declarations after checking active sources, tests and scripts: CookieManagementLink, isColombiaRegion, readForegroundMedia, subscribeForegroundMedia, NzChecklistPhoto and WorkspaceReceipt. Maintained cookie controls, current country validators, playback helpers and receipt schemas remain. These symbols were not published HTTP endpoints. Working old auth/dashboard/shopping and Australian URLs remain compatibility adapters.

Two byte-identical legacy images now share canonical files through explicit rewrites. This removes 1,291,833 repository bytes while preserving both public URLs. The remaining 390 duplicate groups, predominantly Australian mirrors, are retained pending compatibility/provenance review; they are not claimed as visitor bandwidth savings. See ASSET-CONSOLIDATION-70.json and CLEANUP-INVENTORY-56-76.json.
