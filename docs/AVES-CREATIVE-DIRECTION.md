# AVES editorial and collectible direction

Bird stories should be vivid, warm and playful, grounded in observed behaviour and a specific place. Use original writing, verify biological claims and keep metaphor distinct from evidence. Longer stories belong in the bird information view, leaving photographs and map controls clear. A privately retained Spanish motmot reference guides tone; it is not licensed copy for publication.

Plan a reusable collection of species-linked 3D birds: logo-style representations, short flight/idle animations and actual models for a future collectible album or game. Keep stable species identities, source credits, reuse permissions, editable originals and exportable assets. A rendered image or video is separate from a usable 3D model. Recover the prior creation tool and review any existing assets before making replacements. This is a future roadmap requirement, not an implemented game or model library.
